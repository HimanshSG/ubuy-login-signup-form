# Ubuy Login & Signup Form

Simple login and signup form built with plain HTML, CSS and JavaScript.

## What's inside

- Tab switch between Log In and Sign Up
- Login with Password or OTP
- Show/hide password with eye icon
- Get OTP button
- Mailing list checkbox
- reCAPTCHA box
- Basic validation for email, password and captcha
- Works on mobile too
- Welcome screen after login

## Tech used

- HTML5
- CSS3
- Plain JavaScript 
- Font Awesome for icons
- Montserrat from Google Fonts

## How to run

Just open `index.html` in browser.
